# Taller Mecánico RD — Solución Web Comercial QRMOON

Página web comercial moderna para taller mecánico y centro de servicios automotrices en República Dominicana, desarrollada con **Next.js (App Router)**, **TypeScript** y **Tailwind CSS**.

---

## 🚀 Características Principales

1. **Conversión Directa a WhatsApp:**
   - Mensaje unificado prellenado en todos los puntos de contacto:
     > *¡Hola! Quisiera solicitar una cotización y saber más detalles del servicio. (QRMOON) (Taller Mecánico RD)*
   - Teléfono y WhatsApp oficial de atención inmediata: `+1 (829) 499-4321`.
   - Botón flotante permanente y barra inferior fija en dispositivos móviles.

2. **Formulario de Cotización Inteligente:**
   - Captura de datos del vehículo (marca, modelo, año), selección de servicio técnico y descripción del síntoma o avería.
   - Validación interactiva y previsualización del mensaje antes de transferir a WhatsApp.

3. **Catálogo de Servicios Automotrices:**
   - Mantenimiento preventivo (cambio de aceite, filtros, revisión).
   - Diagnóstico computarizado (escáner OBD-II e identificación de códigos de fallo).
   - Frenos (reemplazo de pastillas, discos y calibración).
   - Suspensión y dirección (amortiguadores, terminales y alineación).
   - Aire acondicionado automotriz (carga de refrigerante y limpieza).
   - Reparación mecánica de motor (puesta a punto y corrección de fallas).

4. **Trabajos Realizados y Transparencia:**
   - Galería de intervenciones técnicas con filtro por categorías.
   - Sección de compromiso: comunicación clara antes de reparar, diagnóstico riguroso y honestidad en repuestos.

5. **Ubicación y Canales Oficiales:**
   - Enlace directo a Google Maps: [Ubicación en Google Maps](https://maps.app.goo.gl/H2rKWwfrzkDnj27Y9).
   - Perfil oficial de Instagram: [@qrmoon.rd](https://www.instagram.com/qrmoon.rd/).
   - Perfil oficial de TikTok: [@gato_colonial](https://www.tiktok.com/@gato_colonial).
   - Enlace oficial a Reseñas de Google para opiniones de clientes.

6. **Asistente Virtual (Chatbot Rápido):**
   - Preguntas frecuentes interactivas con autoenfoque y botones de navegación rápida.

## 🛠️ Tecnologías

- **Framework:** Next.js (App Router, React 19) con Exportación Estática
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS
- **Iconos:** Lucide React
- **Cloudflare / Netlify:** Listo para Cloudflare Workers (`wrangler.jsonc`) y Netlify (`netlify.toml`).
